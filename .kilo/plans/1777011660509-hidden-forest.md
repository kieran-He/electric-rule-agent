# 测试全链路：Query改写 + Hybrid + Ragas评估

## 目标
测试一条问题，验证全链路：Query改写 → Hybrid检索 → Ragas评估

## 当前状态
- Hybrid检索：已启用 (`USE_HYBRID_RETRIEVAL=true`)
- Query改写：未启用 (`QUERY_REWRITE_ENABLED` 未配置)
- Query扩展：未启用 (`QUERY_EXPANSION=false`)

## 测试步骤

### Step 1: 启用Query改写配置
修改 `.env` 文件，添加：
```
QUERY_REWRITE_ENABLED=true
QUERY_REWRITE_MIN_LENGTH=10
QUERY_REWRITE_KEEP_ORIGINAL=true
```

### Step 2: 单条问题快速测试
创建简单的测试脚本，测试改写触发和检索：
```python
# scripts/test_rewrite_chain.py
from app.langchain.query_rewriter import QueryRewriter
from app.langchain.llm import MiniMaxLLMWrapper
from app.langchain.hybrid_retriever import HybridRetriever
from app.repository import ChromaPolicyRepository

# 初始化
llm = MiniMaxLLMWrapper()
rewriter = QueryRewriter(llm_wrapper=llm, enabled=True)
repo = ChromaPolicyRepository(...)
hybrid = HybridRetriever(..., query_rewriter=rewriter, use_query_rewrite=True)

# 测试口语化问题（触发改写）
query = "交易规则是什么"  # 包含口语化"是什么"
result = rewriter.rewrite(query)
print(f"改写结果: {result}")

chunks = hybrid.retrieve(query, ["SN"])
print(f"检索结果: {len(chunks)}条")
```

**测试问题**: `"交易规则是什么"` - 包含口语化表达"是什么"，会触发改写

### Step 3: 运行单条Ragas评估
创建简化版ragas测试脚本，只评估1-3条：
```python
# scripts/test_ragas_single.py
from ragas import evaluate
from ragas.metrics import faithfulness, answer_relevancy
from datasets import Dataset

# 单条数据
dataset = Dataset.from_dict({
    "question": ["交易规则是什么"],
    "answer": ["电力市场交易实施细则规定..."],
    "contexts": [["检索到的context..."]],
})

result = evaluate(dataset, metrics=[faithfulness], llm=ragas_llm)
print(result)
```

### Step 4: 验证全链路
- 检查改写是否触发（日志输出）
- 检查检索结果数量
- 检查ragas评估是否成功
