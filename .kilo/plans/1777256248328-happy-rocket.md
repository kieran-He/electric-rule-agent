## 二、是否需要集成到 LangChain Callbacks？

### 对比分析

| 维度 | 自定义 TraceService | LangChain Callbacks | 结论 |
|------|--------------------|--------------------|------|
| **数据存储** | ✅ TraceRecord 表（SQLAlchemy） | ⚠️ 需配置 LangSmith 或自定义 Handler | **自定义更灵活** |
| **业务字段** | ✅ rerank_scores, latency_ms, filters | ⚠️ 标准 Callback 仅记录 input/output | **自定义更强** |
| **查询分析** | ✅ 按 trace_id/session_id 查询 | ⚠️ LangSmith 需付费 | **自定义更经济** |
| **自动追踪** | ❌ 手动调用 save_trace() | ✅ 自动记录 LLM/Retrieval calls | **LangChain 更好** |
| **Token 计数** | ❌ 未实现 | ✅ 自动统计 input/output tokens | **LangChain 更强** |
| **细粒度追踪** | ❌ 仅总延迟 | ✅ 每个步骤自动记录 | **LangChain 更好** |
| **与现有架构一致** | ✅ SQLAlchemy（与 ConversationTurn 一致） | ⚠️ 需引入新机制 | **自定义更好** |

### 优化 2：添加 LangChain CallbackHandler（推荐优先级：⭐⭐⭐⭐）

**目的**：自动追踪每个步骤，补充细粒度性能数据。

#### 2.1 创建自定义 CallbackHandler

```python
# app/langchain/trace_callback.py
from langchain.callbacks.base import BaseCallbackHandler
from typing import Any, Dict, List
import time

class TraceCallbackHandler(BaseCallbackHandler):
    """
    Custom callback handler for automatic trace recording.
    
    Records:
    - LLM start/end time, Token usage
    - Retrieval start/end time, document count
    - Chain execution steps
    """
    
    def __init__(self, trace_id: str, session_id: str):
        self.trace_id = trace_id
        self.session_id = session_id
        self._llm_start_time = None
        self._retrieval_start_time = None
        self._token_usage = {}
    
    def on_llm_start(self, serialized: Dict[str, Any], prompts: List[str], **kwargs: Any):
        self._llm_start_time = time.time()
    
    def on_llm_end(self, response: Any, **kwargs: Any):
        llm_latency = int((time.time() - self._llm_start_time) * 1000)
        
        # ✅ 自动提取 Token usage
        token_usage = response.llm_output.get("token_usage", {})
        self._token_usage = {
            "input_tokens": token_usage.get("prompt_tokens", 0),
            "output_tokens": token_usage.get("completion_tokens", 0),
            "llm_latency_ms": llm_latency,
        }
    
    def on_retriever_start(self, serialized: Dict[str, Any], query: str, **kwargs: Any):
        self._retrieval_start_time = time.time()
    
    def on_retriever_end(self, documents: List[Any], **kwargs: Any):
        retrieval_latency = int((time.time() - self._retrieval_start_time) * 1000)
        self._retrieval_stats = {
            "doc_count": len(documents),
            "retrieval_latency_ms": retrieval_latency,
        }
    
    def get_token_usage(self) -> dict:
        return self._token_usage
    
    def get_retrieval_stats(self) -> dict:
        return self._retrieval_stats
```

#### 2.2 Orchestrator 使用 CallbackHandler

```python
# app/langchain/orchestrator_hybrid.py
def run(self, req: QueryRequest, ...):
    trace_id = f"trace_{uuid.uuid4().hex[:12]}"
    
    # ✅ 创建 CallbackHandler
    callback_handler = TraceCallbackHandler(trace_id, req.session_id)
    
    # ✅ LLM 调用时自动追踪
    answer = self.llm_wrapper.invoke(
        prompt,
        system=system_prompt,
        callbacks=[callback_handler]  # ✅ 自动记录
    )
    
    # ✅ Retrieval 时自动追踪
    chunks = self.hybrid_retriever.retrieve(
        req.query,
        province_codes,
        callbacks=[callback_handler]  # ✅ 自动记录
    )
    
    # ✅ 获取 Token 和 Retrieval 统计
    token_usage = callback_handler.get_token_usage()
    retrieval_stats = callback_handler.get_retrieval_stats()
    
    # ✅ 保存到 TraceService
    if trace_service:
        trace_service.save_trace(
            trace_id=trace_id,
            session_id=req.session_id,
            input_tokens=token_usage.get("input_tokens", 0),
            output_tokens=token_usage.get("output_tokens", 0),
            latency_ms=...,
        )
```

**优势**：
- 自动追踪 LLM/Retrieval（无需手动计时）
- 自动 Token 计数
- 细粒度性能数据（每个步骤）

### 优化 6：Batch Insert（推荐优先级：⭐⭐）

**当前问题**：
- 每次 trace 单独插入（频繁 DB 操作）
- 高并发时性能瓶颈

**改进方案**：

#### 6.1 TraceBatchRepository

```python
# app/db/repositories/trace_batch_repo.py
class TraceBatchRepository:
    def __init__(self, batch_size: int = 100):
        self._batch: list[TraceRecord] = []
        self._batch_size = batch_size
    
    def add_trace(self, trace: TraceRecord):
        self._batch.append(trace)
        
        if len(self._batch) >= self._batch_size:
            self._flush()
    
    def _flush(self):
        with self.session_factory() as db:
            db.bulk_save_objects(self._batch)
            db.commit()
            self._batch.clear()
```

#### 6.2 Orchestrator 使用 Batch Insert
