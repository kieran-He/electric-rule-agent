# 飞书机器人去重优化方案

## 问题分析

### 飞书重试机制（官方文档）

**失败重发机制**：
- 响应超时：3秒
- 重试间隔：15秒 → 5分钟 → 1小时 → **6小时**
- 最多重试 4 次

**成功重发机制**：
- 飞书使用"至少发送一次"策略
- 即使成功响应也可能收到重复消息

**幂等 key 建议**：
- v1.0 事件：使用 `uuid`
- v2.0 事件：使用 `header.event_id`

### 当前代码问题

| 问题 | 当前值 | 应改为 |
|------|--------|--------|
| TTL | 3600秒 (1小时) | 86400秒 (24小时) |
| 幂等 key | `message.message_id` | `data.header.event_id` 或 `data.uuid` |
| 字段名 | `message_id` | `event_id` |

**lark SDK 数据结构** (`lark_oapi/event/context.py`):
```python
class EventHeader:
    event_id: str      # v2.0 事件唯一标识

class EventContext:
    uuid: str          # v1.0 事件唯一标识
    header: EventHeader  # v2.0 header
```

class ProcessedMessage(Base):
    __tablename__ = "processed_messages"

    event_id: Mapped[str] = mapped_column(String(64), primary_key=True)
    created_at: Mapped[datetime] = mapped_column(DateTime, default=datetime.utcnow, nullable=False)

    __table_args__ = (
        Index('ix_processed_messages_created_at', 'created_at'),
    )

#### 步骤 2：修改 FeishuBotService

**文件**: `app/services/feishu_bot_service.py`

1. TTL 从 3600 改为 86400
2. 使用 `event_id` 作为去重 key
3. 从 `data` 参数中提取 `event_id`

```python
class FeishuBotService:
    def __init__(self, ...):
        self._processed_ttl = 86400  # 24 小时

    def _get_event_id(self, data: lark.im.v1.P2ImMessageReceiveV1) -> str:
        # v2.0 事件使用 header.event_id，v1.0 使用 uuid
        if data.header and data.header.event_id:
            return data.header.event_id
        return data.uuid or ""

    def _check_and_mark(self, event_id: str) -> bool:
        if not event_id:
            return False
        with self.session_factory() as session:
            try:
                existing = session.query(ProcessedMessage).filter(
                    ProcessedMessage.event_id == event_id
                ).first()
                if existing:
                    return True
                
                cutoff = datetime.utcnow() - timedelta(seconds=self._processed_ttl)
                session.query(ProcessedMessage).filter(
                    ProcessedMessage.created_at < cutoff
                ).delete()
                
                session.add(ProcessedMessage(event_id=event_id))
                session.commit()
                return False
            except Exception:
                session.rollback()
                raise

    def handle_message(self, data: lark.im.v1.P2ImMessageReceiveV1) -> None:
        if not data.event or not data.event.message:
            return
        
        event_id = self._get_event_id(data)
        if self._check_and_mark(event_id):
            logger.debug(f"Duplicate event {event_id}, skipping")
            return
        
        # ... 后续处理
```

## 额外说明：快速响应已实现

当前 `app/feishu_bot.py:50-52` 已经使用线程池异步处理：
```python
def _handle_message(self, data: lark.im.v1.P2ImMessageReceiveV1) -> None:
    if self.service:
        self.executor.submit(self.service.handle_message, data)
```

这确保了 `_handle_message` 会立即返回，SDK 能在 3 秒内响应飞书。去重逻辑在异步任务中执行，不影响响应时间。
