# 代码仓库整理计划

## 一、项目运行逻辑分析

### 1.1 当前版本架构 (v3.0.0)

**主入口**: `app/main.py` (FastAPI应用)

**核心模块结构**:
```
app/
├── main.py                 # FastAPI入口，包含lifespan管理
├── config.py               # 配置管理(Settings类)
├── api/                    # API路由层
│   ├── routes_query.py     # 查询接口 (/query)
│   ├── routes_admin.py     # 管理接口 (/admin)
│   ├── routes_ingest.py    # 数据摄入接口 (/admin/ingest)
│   └── routes_metrics.py   # 监控指标接口 (/metrics)
├── services/               # 业务服务层
│   ├── query_service.py    # 查询服务(直接使用混合检索)
│   ├── ingest_service.py   # 数据摄入服务
│   ├── conversation_service.py  # 会话管理
│   ├── trace_service.py    # 追踪服务
│   ├── feishu_bot_service.py    # 飞书机器人服务
│   ├── session_cleanup.py  # 会话清理任务
│   ├── history_summarizer.py    # 历史摘要
│   ├── ingest/ingestion_pipeline.py  # 摄入管道
│   ├── memory/             # 内存管理(预留)
│   └── retrieval/          # 检索服务(预留)
├── schemas/                # Pydantic数据模型
│   ├── query.py            # 查询请求/响应
│   ├── answer.py           # 回答模型
│   ├── ingest.py           # 摄入请求/响应
│   ├── admin.py            # 管理接口模型
│   └── error.py            # 错误响应
├── db/                     # 数据库层
│   ├── session.py          # SQLAlchemy会话
│   ├── base.py             # 基础模型
│   ├── models/             # ORM模型
│   └── repositories/       # 数据仓库
├── langchain/              # LangChain集成层(仅混合检索)
│   ├── orchestrator_hybrid.py  # 混合检索编排器(唯一版本)
│   ├── hybrid_retriever.py # 混合检索器(BM25+向量)
│   ├── llm.py              # MiniMax LLM包装器
│   ├── chains.py           # LCEL链
│   ├── bm25_indexer.py     # BM25索引器
│   ├── reranker_cache.py   # 重排序器缓存
│   ├── query_expander.py   # 查询扩展(可选启用)
│   ├── query_rewriter.py   # 查询重写(可选启用)
│   ├── retriever_wrapper.py # Chroma检索器包装
│   └── prompts.py          # Prompt模板
├── core/                   # 核心功能
│   ├── dependency.py       # 依赖注入
│   ├── logger.py           # 日志配置
│   ├── logging_context.py  # 日志上下文
│   ├── exceptions.py       # 异常定义
│   ├── metrics.py          # 性能指标收集
│   ├── health_check.py     # 健康检查
│   ├── feishu_alert.py     # 飞书告警
│   └── cache.py            # 缓存
└── utils/                  # 工具函数
    ├── hash.py, text.py, time.py
```

**运行流程**:
1. `app/main.py` 启动FastAPI，注册路由，初始化数据库
2. `app/core/dependency.py` 提供服务依赖注入
3. `app/services/query_service.py` 直接使用 `HybridQAOrchestrator` (混合检索版本)
4. `HybridQAOrchestrator` 调用以下组件:
   - `app/core/repository.py` (ChromaPolicyRepository) 进行向量检索
   - `app/langchain/hybrid_retriever.py` (BM25+向量融合检索)
   - `app/langchain/query_rewriter.py` (查询重写，可选启用)
   - `app/langchain/query_expander.py` (查询扩展，可选启用)
   - `app/langchain/reranker_cache.py` (语义重排序)
   - `app/core/llm_client.py` 或 `app/langchain/llm.py` (LLM生成)

### 1.2 飞书机器人入口

**入口文件**: `app/feishu_bot.py`
- 使用lark-oapi WebSocket长连接
- 调用 `app/services/feishu_bot_service.py` 处理消息
- 消息去重使用 `app/db/models/processed_message.py`
