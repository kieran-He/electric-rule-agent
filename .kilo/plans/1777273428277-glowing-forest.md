# 飞书机器人参考文献格式优化

## 需求

将参考文献输出格式从：
```
1.  - 一 > 总 则
```
改为：
```
1. 《文献名》一 > 总 则
```

## 修改文件

- `app/services/feishu_bot_service.py:73-77` - 修改 `_format_reply` 方法中的 citation 格式化逻辑

## 实施步骤

1. 修改 `_format_reply` 中 citation 格式：
   - 当前：`f"{i}. {citation.doc_name}"` + `f" - {citation.title_path}"`
   - 改为：`f"{i}. 《{citation.doc_name}》{citation.title_path}"`

## 修改前后对比

**修改前：**
```python
doc_info = f"{i}. {citation.doc_name}"
if citation.title_path:
    doc_info += f" - {citation.title_path}"
```

**修改后：**
```python
doc_info = f"{i}. 《{citation.doc_name}》{citation.title_path}"
```
