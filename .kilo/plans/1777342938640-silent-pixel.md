# 飞书消息 Markdown 格式渲染优化计划

## 问题分析

当前飞书机器人输出显示原始 Markdown 符号（如 `**加粗**`），未正确渲染。

**原因**: 当前使用 `msg_type="text"` 发送纯文本，飞书不支持 Markdown 渲染。

## 解决方案

将 Markdown 转换为飞书富文本格式 (`msg_type="post"`)

---

## 飞书富文本格式

飞书 post 消息 JSON 结构：

```json
{
  "zh_cn": {
    "title": "消息标题",
    "content": [
      [
        {"tag": "text", "text": "普通文本"},
        {"tag": "b", "text": "加粗文本"},
        {"tag": "a", "text": "链接", "href": "https://example.com"},
        {"tag": "code", "text": "代码"}
      ],
      [
        {"tag": "text", "text": "第二段"}
      ]
    ]
  }
}
```

---

## Markdown 到飞书富文本映射

| Markdown | 飞书富文本 | 处理方式 |
|----------|-----------|----------|
| `**加粗**` | `{"tag": "b", "text": "加粗"}` | 直接转换 |
| `` `代码` `` | `{"tag": "code", "text": "代码"}` | 直接转换 |
| `[链接](url)` | `{"tag": "a", "text": "链接", "href": "url"}` | 直接转换 |
| `# 标题` | 作为段落开头加粗文本 | 转为 `{"tag": "b", "text": "标题"}` |
| `## 二级标题` | 同上 | 同上 |
| `> 引用` | 无直接支持 | 转为普通文本加前缀 `> ` |
| `- 列表项` | 无直接支持 | 转为普通文本加前缀 `• ` |
| `| 表格 |` | 无直接支持 | 转为文本列表格式 |
| `---分隔线` | 无直接支持 | 转为空段落 |

### 2. 解析策略

使用正则表达式逐步解析：

1. **解析段落**: 按 `\n\n` 分割
2. **解析标题**: `^#{1,6} (.+)$`
3. **解析加粗**: `\*\*(.+?)\*\*`
4. **解析代码**: `` `(.+?)` ``
5. **解析链接**: `\[(.+?)\]\((.+?)\)`
6. **解析列表**: `^[-*] (.+)$`
7. **解析表格**: 简单表格转为文本列表
8. **解析引用**: `^> (.+)$`

## 实现细节

### markdown_to_feishu.py 核心逻辑

```python
import re
import json

class MarkdownToFeishuConverter:
    def __init__(self):
        self.bold_pattern = re.compile(r'\*\*(.+?)\*\*')
        self.code_pattern = re.compile(r'`(.+?)`')
        self.link_pattern = re.compile(r'\[(.+?)\]\((.+?)\)')
        self.header_pattern = re.compile(r'^#{1,6}\s+(.+)$')
        self.list_pattern = re.compile(r'^[-*]\s+(.+)$')
        self.quote_pattern = re.compile(r'^>\s+(.+)$')
    
    def convert(self, text: str) -> dict:
        paragraphs = text.split('\n\n')
        content = []
        
        for para in paragraphs:
            para = para.strip()
            if not para:
                continue
            
            # 处理表格（特殊处理）
            if '|' in para and para.count('|') > 2:
                blocks = self._convert_table(para)
                content.extend(blocks)
                continue
            
            # 处理标题
            if self.header_pattern.match(para):
                blocks = self._convert_header(para)
                content.append(blocks)
                continue
            
            # 处理列表
            if self.list_pattern.match(para):
                blocks = self._convert_list(para)
                content.append(blocks)
                continue
            
            # 处理普通段落（含 inline 格式）
            blocks = self._convert_paragraph(para)
            content.append(blocks)
        
        return {"zh_cn": {"title": "", "content": content}}
    
    def _convert_paragraph(self, text: str) -> list:
        """Convert paragraph with inline formatting."""
        blocks = []
        remaining = text
        
        while remaining:
            # 查找最近的格式标记
            match = self._find_next_match(remaining)
            
            if not match:
                # 无格式，直接输出文本
                if remaining:
                    blocks.append({"tag": "text", "text": remaining})
                break
            
            # 输出匹配前的文本
            if match.start() > 0:
                blocks.append({"tag": "text", "text": remaining[:match.start()]})
            
            # 输出匹配的格式
            if match.pattern == self.bold_pattern:
                blocks.append({"tag": "b", "text": match.group(1)})
            elif match.pattern == self.code_pattern:
                blocks.append({"tag": "code", "text": match.group(1)})
            elif match.pattern == self.link_pattern:
                blocks.append({"tag": "a", "text": match.group(1), "href": match.group(2)})
            
            remaining = remaining[match.end():]
        
        return blocks
    
    def _convert_header(self, text: str) -> list:
        """Convert Markdown header to bold text."""
        match = self.header_pattern.match(text)
        if match:
            return [{"tag": "b", "text": match.group(1)}]
        return [{"tag": "text", "text": text}]
    
    def _convert_list(self, text: str) -> list:
        """Convert Markdown list to text with bullets."""
        items = text.split('\n')
        blocks = []
        for item in items:
            match = self.list_pattern.match(item)
            if match:
                blocks.append({"tag": "text", "text": "• " + match.group(1)})
        return blocks
    
    def _convert_table(self, text: str) -> list:
        """Convert Markdown table to text representation."""
        lines = text.split('\n')
        blocks = []
        for line in lines:
            if line.strip().startswith('|'):
                cells = [c.strip() for c in line.split('|') if c.strip()]
                if cells and not all(c.replace('-', '').strip() == '' for c in cells):
                    row_text = ' | '.join(cells)
                    blocks.append({"tag": "text", "text": row_text})
        return blocks
```

## 注意事项

1. **飞书限制**:
   - 单条消息最多 10000 字符
   - 单个段落最多 20 个 inline 元素
   - 不支持斜体、删除线、图片

2. **表格处理**（已确认）:
   - 转为文本列表格式
   - 表格行转为 `| 分隔的文本行`

3. **分段策略**:
   - 按 `\n\n` 分割段落
   - 每个段落是一个 list 元素

4. **临时回复**:
   - 保持 text 类型（简单快速）
   - 最终答案使用 post 类型（格式化）

5. **处理范围**（已确认）:
   - 全部格式：加粗、链接、代码、标题、列表、引用、表格
