## 问题诊断

### 当前状态
- **实验已完成**: 100条陕西问题的 Baseline 和 Hybrid 结果已生成
- **Ragas评估未生效**: ragas_scores.json 中所有分数为 null
- **原因**: 实验脚本未加载 .env 文件，导致 LLM_API_KEY 等环境变量未传递给 RagasEvaluator

### 核心问题
```python
# run_experiment.py 缺少这行关键代码：
from dotenv import load_dotenv
load_dotenv()
```

当前脚本直接使用 `os.getenv()` 但未加载 `.env` 文件，导致：
- LLM_API_KEY = ""
- LLM_ENDPOINT = ""
- RagasEvaluator 初始化失败
- ragas.is_available() 返回 False
- evaluate_batch() 返回空结果

    llm_endpoint=os.getenv("RAGAS_ENDPOINT"),
    llm_api_key=os.getenv("RAGAS_API_KEY"),
    llm_model=os.getenv("RAGAS_MODEL"),
)

# 重新检索 contexts 并评估

    # 存储用于 Ragas 评估
    baseline_questions.append(question)
    baseline_answers.append(answer)
    baseline_contexts.append(contexts)

# 同样处理 Hybrid

# 运行 Ragas 评估
baseline_ragas = ragas_evaluator.evaluate_batch(...)
hybrid_ragas = ragas_evaluator.evaluate_batch(...)

# 更新文件
update_ragas_scores(baseline_ragas, hybrid_ragas)
update_metrics_summary()
update_reports()
