# LLM查询改写优化计划

## 目标
实现LLM驱动的查询改写功能，将用户模糊/口语化查询转换为更适合检索的精确形式，预计提升10-15%检索命中率。

## 实现方案

### 1. 新增模块：`app/langchain/query_rewriter.py`

**核心类：QueryRewriter**
```python
@dataclass
class RewriteResult:
    rewritten_query: str
    confidence: float
    triggered: bool
    trigger_reason: str

class QueryRewriter:
    """
    LLM驱动的查询改写器
    
    智能触发：只对模糊/口语化查询改写
    并行检索：改写结果与原查询并行检索，合并去重
    """
    
    DOMAIN_KEYWORDS = ["电力", "交易", "结算", "现货", "中长期", "零售", "辅助", "储能", "调频"]
    COLLOQUIAL_PATTERNS = ["怎么", "如何", "那个", "这个", "什么", "哪些", "有没有"]
    
    def __init__(self, llm_wrapper: MiniMaxLLMWrapper, enabled: bool = True):
        self.llm = llm_wrapper
        self.enabled = enabled
    
    def should_rewrite(self, query: str) -> tuple[bool, str]:
        """判断是否需要改写"""
        if len(query) < 10:
            return True, "too_short"
        if not any(kw in query for kw in self.DOMAIN_KEYWORDS):
            return True, "missing_domain_keyword"
        if any(p in query for p in self.COLLOQUIAL_PATTERNS):
            return True, "colloquial_expression"
        return False, ""
    
    def rewrite(self, query: str) -> RewriteResult:
        """执行改写"""
        should, reason = self.should_rewrite(query)
        if not should or not self.enabled:
            return RewriteResult(query, 1.0, False, reason)
        
        prompt = self._build_rewrite_prompt(query)
        result = self.llm.invoke(prompt, system=self._system_prompt())
        
        rewritten = self._parse_result(result)
        return RewriteResult(rewritten, 0.8, True, reason)
```

```
请将此查询改写为更适合检索的形式：
1. 补充领域关键词（如"交易规则" -> "电力市场交易实施细则"）

输出JSON格式：

```

## 设计决策（已确认）

1. **改写触发策略**：智能触发 - 只对模糊/口语化查询改写
2. **并行检索策略**：并行检索 - 同时使用改写结果和原查询检索，合并去重
3. **延迟容忍**：允许200-500ms延迟，第一版不需要缓存优化

## 智能触发判断逻辑

当查询满足以下任一条件时触发改写：
- 查询长度 < 10字符（过于简短）
- 缺乏领域关键词（如不包含"电力"、"交易"、"结算"等）
- 包含口语化表达（如"怎么"、"如何"、"那个"、"这个"）
- 包含疑问代词但无具体内容（如"有什么政策"、"规定是什么"）
- 置信度阈值触发（可选：向量检索top score < 0.6时触发）

## 并行检索合并策略

1. 原查询检索 → vector_chunks + bm25_chunks
2. 改写查询检索 → rewritten_chunks
3. 合并去重 → 按text hash去重
4. 重排序 → BGE Rerank统一排序
5. 返回final_top_k结果
