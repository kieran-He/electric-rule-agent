## 三、可优化方向

### 3.1 MetricsStore 持久化（计划文档优化 3）

**当前问题**：
- MetricsStore 仅内存存储（重启丢失）
- 无法查询历史性能数据
- 无法进行趋势分析

**优化方案**：
```python
# 新建 app/db/models/metrics_record.py
class MetricsRecord(Base):
    id: Mapped[int]
    trace_id: Mapped[str]
    retrieval_latency_ms: Mapped[int]
    llm_latency_ms: Mapped[int]
    total_latency_ms: Mapped[int]
    input_tokens: Mapped[int]
    output_tokens: Mapped[int]
    created_at: Mapped[datetime]

# MetricsStore.save_to_db()
def save_to_db(self, trace_id: str, session_factory):
    with session_factory() as db:
        record = MetricsRecord(
            trace_id=trace_id,
            retrieval_latency_ms=self._retrieval_latency[-1].value,
            ...
        )
        db.add(record)
        db.commit()
```

**收益**：
- 历史性能数据查询
- 趋势分析（每日 Token 消耗）
- 对接飞书仪表盘

**预估工时**：1.5h

---

### 3.2 错误追踪增强（计划文档优化 5）

**当前问题**：
- MetricsStore 仅记录 error_counts
- 缺少错误详情（stack trace）
- 无法关联 trace_id

**优化方案**：
```python
# TraceRecord 已包含 error_type/error_message/success
# 需在 orchestrator 中记录错误

def run(self, req: QueryRequest, ...):
    try:
        answer, input_tokens, output_tokens = self.llm.invoke(...)
        
        trace_service.save_trace(
            trace_id=trace_id,
            success=True,
            input_tokens=input_tokens,
            ...
        )
        
    except LLMError as e:
        metrics_store.record_error("llm_error")
        
        trace_service.save_trace(
            trace_id=trace_id,
            success=False,
            error_type="llm_error",
            error_message=str(e),
            ...
        )
        raise
```

**收益**：
- 错误详情存储（便于问题定位）
- 错误类型统计（优化方向）
- 飞书错误报警推送

**预估工时**：1h

#### 3.3.1 飞书 Webhook 报警

```python
# app/core/feishu_alert.py
import requests

class FeishuAlertHandler(logging.Handler):
    def emit(self, record):
        if record.levelno >= logging.ERROR:
            payload = {
                "msg_type": "text",
                "content": {
                    "text": f"⚠️ ERROR: {record.getMessage()}\ntrace_id: {record.trace_id}"
                }
            }
            requests.post(FEISHU_WEBHOOK_URL, json=payload)

# logger.py 中添加
feishu_handler = FeishuAlertHandler()
feishu_handler.addFilter(LoggingContextFilter())
root.addHandler(feishu_handler)
```

**收益**：错误实时推飞书群
