# 飞书机器人重复回复问题修复方案

## 问题分析

### 当前去重机制
`feishu_bot_service.py` 已实现消息去重：
- `_processed_messages: deque` 存储 1000 条已处理消息
- `_is_duplicate(message_id)` 检查是否重复（TTL 300秒）
- `_mark_processed(message_id)` 标记已处理

### 问题根因
`_is_duplicate()` 和 `_mark_processed()` 分开调用（第90-94行），存在并发窗口：

```python
if self._is_duplicate(message_id):  # 线程A检查: 不重复
    return                          # 线程B检查: 不重复（同时）
self._mark_processed(message_id)    # 线程A标记
                                   # 线程B标记（两个线程都处理了）
```

两个线程可能同时通过检查后各自处理消息，导致重复回复。

## 修复方案

### 方案：原子化去重检查

将 `_is_duplicate` 和 `_mark_processed` 合并为单一原子操作 `_check_and_mark`：

```python
def _check_and_mark(self, message_id: str) -> bool:
    """
    Atomically check if message is duplicate and mark as processed.
    
    Returns:
        True if message was already processed (should skip)
        False if message is new (proceed with processing)
    """
    with self._lock:
        now = time.time()
        # Clean expired entries
        while self._processed_messages and now - self._processed_messages[0][1] > self._processed_ttl:
            self._processed_messages.popleft()
        # Check if already processed
        for mid, _ in self._processed_messages:
            if mid == message_id:
                return True  # Duplicate, skip
        # Mark as processed
        self._processed_messages.append((message_id, now))
        return False  # New message, proceed
```

### 修改 handle_message

