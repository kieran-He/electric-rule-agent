# 问答回复质量优化方案

## 问题分析

### 1. 提示词问题
**现状**：提示词在多处定义，要求 LLM "引用证据时标注来源文档名称"，导致 LLM 在正文中频繁标注 `证据来源: 证据x`，影响阅读体验。

**相关文件**：
- `app/langchain/prompts.py:9-15` - QA_SYSTEM_PROMPT 定义
- `app/langchain/orchestrator.py:191-197` - 实际使用的 system_prompt
- `app/langchain/orchestrator_hybrid.py:206-212` - hybrid 版本的 system_prompt

**当前提示词**：
```
你是电力政策问答助手。只能根据提供的证据回答，禁止编造。如果证据不足，明确说明"未检索到充分依据"。

回答要求：
1. 基于证据内容回答，不要添加证据中没有的信息
2. 引用证据时标注来源文档名称
3. 如果问题涉及多个省份，分别说明各省份的政策
4. 如果证据不足，明确告知用户并建议补充检索
```

### 2. 引用数量问题
**现状**：top_k 配置为12，但 `_build_citations` 方法硬编码 `chunks[:5]`，只显示前5个引用。

**相关文件**：
- `app/langchain/orchestrator.py:230` - `chunks[:5]` 硬编码
- `app/langchain/orchestrator_hybrid.py` 继承此方法

### 3. 飞书回复格式
**现状**：`_format_reply` 方法显示所有引用详情（doc_name, article_no, title_path），格式冗长。

**相关文件**：
- `app/services/feishu_bot_service.py:67-79` - `_format_reply` 方法

## 优化方案

### 方案1：优化提示词（推荐）

**修改位置**：`app/langchain/orchestrator.py:191-197` 和 `orchestrator_hybrid.py:206-212`

**新提示词**：
```
你是电力政策问答助手。只能根据提供的证据回答，禁止编造。如果证据不足，明确说明"未检索到充分依据"。

回答格式要求：
1. 直接回答用户问题，正文不要标注来源编号
2. 结构清晰，使用标题和列表组织内容
3. 如需引用原文，使用引用格式（> 引用内容）
4. 证据不足时，明确告知用户并建议补充检索
5. 涉及多省份时，分别说明各省份政策

注意：引用来源会在回答末尾自动展示，无需在正文标注。
```

**优点**：
- 正文简洁清晰
- 引用来源统一放在末尾
- 用户阅读体验更好

### 方案2：调整引用数量

**修改位置**：`app/langchain/orchestrator.py:230`

**方案A - 配置化**：
```python

    ...
```

**方案B - 新增配置项**：
在 `config.py` 添加 `max_citations` 配置项，允许单独控制引用显示数量。

### 方案3：简化飞书引用格式

**修改位置**：`app/services/feishu_bot_service.py:67-79`

**新格式**：
```python
def _format_reply(self, answer: QueryAnswer) -> str:
    lines = [answer.answer]
    if answer.citations:
        lines.append("\n---")
        lines.append("**参考文献：**")
        for i, citation in enumerate(answer.citations, 1):
            # 只显示文档名和章节
            doc_info = f"{i}. {citation.doc_name}"
            if citation.title_path:
                doc_info += f" - {citation.title_path}"
            lines.append(doc_info)
    return "\n".join(lines)
```

**优点**：
- 引用格式简洁（文档名 + 章节）
- 去除 article_no、excerpt 等冗余信息
