# 飞书卡片 JSON 2.0 结构升级计划

## 目标

将 `markdown_to_feishu.py` 中的卡片结构从 JSON 1.0 升级到 JSON 2.0，以支持完整的 Markdown 语法渲染。

---

## JSON 1.0 vs JSON 2.0 对比

| 特性 | JSON 1.0 | JSON 2.0 |
|------|----------|----------|
| Markdown 标题 | 不支持 | ✅ 支持 `#` 到 `######` |
| Markdown 引用 | 不支持 | ✅ 支持 `> 引用` |
| Markdown 表格 | 不支持 | ✅ 支持 `| 表格 |` |
| Markdown 代码块 | 不支持 | ✅ 支持 ``` 代码块 ``` |
| 分隔线 | 不支持 | ✅ 支持 `---` |
| 结构 | `elements` 在根层级 | `elements` 在 `body` 内 |

---

## 修改内容

### 文件：`app/utils/markdown_to_feishu.py`

**当前结构 (JSON 1.0):**
```python
{
    "config": {"update_multi": True},
    "elements": [{"tag": "markdown", "content": text}]
}
```

**目标结构 (JSON 2.0):**
```python
{
    "schema": "2.0",
    "config": {"update_multi": True},
    "body": {
        "elements": [{"tag": "markdown", "content": text}]
    }
}
```

---

## 修改步骤

1. 修改 `convert_to_interactive()` 方法，添加 `"schema": "2.0"`
2. 将 `elements` 移入 `body` 对象内
3. 同步修改 `_empty_interactive()` 方法保持一致

---

## 预期效果

修改后，飞书卡片将支持完整 Markdown 渲染：

- `## 一、交易种类` → 渲染为二级标题样式
- `> 引用文本` → 渲染为引用块样式
- `| 交易品种 | 说明 |` → 渲染为表格样式
- `---` → 渲染为分隔线

---

## 注意事项

- JSON 2.0 需要 Feishu 客户端版本 7.20+，低版本客户端显示升级提示
- 其他代码无需修改，`feishu_bot_service.py` 已正确使用 `PatchMessageRequest`
