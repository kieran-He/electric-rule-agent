# 飞书参考文献格式修复计划

## 问题分析

### 当前输出格式（错误）
```
参考文献：
1. 十二 > 风险防控及争议处理
2. 执行事项
```

### 根本原因（已定位）

**BM25Indexer 数据字段映射错误**

**JSON数据结构** (`data/processed/*.json`):
```json
{
  "clauses": [{
    "doc_name": "陕西省2026年电力市场方案",  // 存在
    "source_name": "不存在此字段",           // 不存在！
    "page_start": 1,                         // 存在
    "page_end": 5                            // 存在
  }]
}
```

**BM25Indexer错误代码** (`app/langchain/bm25_indexer.py:114-120`):
```python
self.metadatas.append({
    "source_name": clause.get("source_name", ""),  # 用错字段名！
    # 缺少 page_start, page_end
})
```

**结果**: `source_name` 获取到空字符串，`page_start/page_end` 未存储

---

## 确认的期望格式

**docname + titlepath + pagestart + pageend**

示例输出：
```
参考文献：
1. 陕西2026年电力市场方案 > 十二 > 风险防控 (P15-17)
```

---

## 修复方案

### 修改1: BM25Indexer - 修正字段映射

**文件**: `app/langchain/bm25_indexer.py:114-120`

```python
# 当前（错误）
self.metadatas.append({
    "source_name": clause.get("source_name", ""),
    ...
})

# 修改为
self.metadatas.append({
    "doc_name": clause.get("doc_name", ""),
    "source_name": clause.get("doc_name", ""),  # 兼容旧字段名
    ...
    "page_start": clause.get("page_start"),
    "page_end": clause.get("page_end"),
})
```

### 修改2: feishu_bot_service - 优化格式化

**文件**: `app/services/feishu_bot_service.py:82-90`

```python
def _format_reply(self, answer: QueryAnswer) -> str:
    lines = [answer.answer]
    if answer.citations:
        lines.append("\n---")
        lines.append("参考文献：")
        for i, citation in enumerate(answer.citations, 1):
            parts = []
            if citation.doc_name:
                parts.append(citation.doc_name)
            if citation.title_path:
                parts.append(citation.title_path)
            
            doc_info = f"{i}. {' > '.join(parts)}"
            
            if citation.page_start and citation.page_end:
                doc_info += f" (P{citation.page_start}-{citation.page_end})"
            elif citation.page_start:
                doc_info += f" (P{citation.page_start})"
            
            lines.append(doc_info)
    return "\n".join(lines)
```
